# 자동차 경주

## 개요

초간단 자동차 경주 게임을 구현한다.

사용자는 자동차 이름과 게임 진행 횟수를 입력 받는다. 이후 전진 조건에 따라 자동차를 전진 또는 멈춘다. 모든 라운드가 진행된 후, 1대 이상의 우승자를 출력한다.

## 기능 구현 목록

- [ ]  사용자 입력 받기
    - [ ]  경주 자동차 이름 입력 받기
    - [ ]  경기 시도 횟수 입력 받기
- [ ]  입력 값 파싱하기
    - [ ]  쉼표(,)로 입력 값을 파싱하기
    - [ ]  경기 시도 횟수 Integer 자료형으로 변환하기
- [ ]  입력 값 유효성 검사 (`IllegalArgumentException` 발생 시킴)
    - [ ]  경주 자동차 이름 예외처리
        - [ ]  공백 및 null 값 예외 처리
        - [ ]  중복된 이름 예외 처리
        - [ ]  5자 이상 입력된 이름 예외 처리
    - [ ]  경기 시도 횟수 예외처리
        - [ ]  숫자가 아닌 값 입력시 예외 처리
        - [ ]  실수 값 입력시 예외 처리
        - [ ]  Integer값을 벗어나는 경기 시도 횟수 입력시 예외 처리
        - [ ]  0 및 음수 값 입력시 예외 처리
- [ ]  자동차 경주 진행 구현
    - [ ]  라운드 마다 0 에서 9 사이의 무작위 값을 구해서 무작위 값이 4 이상인 경우 전진 시키고 아니면 멈추기
    - [ ]  모든 라운드가 끝난 후, 자동차 경주 게임의 우승자를 찾기
- [ ]  값 출력 하기
    - [ ]  각 라운드 별 자동차 진행 상황 출력 ⇒ “이름 : -” 형식으로 보여주기
    - [ ]  최종 우승 자동차 이름 출력 (공동 우승 가능, 우승자가 여러명 일시 쉼표(,)로 구분하여 출력) ⇒ “최종 우승자 : “A”, “B”형식으로 보여주기
- [ ]  테스트 코드 작성
    - [ ]  각 기능 별로 실행을 확인할 수 있는 테스트 코드 작성

## 고려 사항

- JDK 21 버전에서 실행 가능한가?
- `Application`의 `main()`에서 프로그램이 시작하는가?
- `build.gradle` 파일은 변경하지 않았는가?
- 제공된 라이브러리 이외의 외부 라이브러리를 사용하지 않았는가?
- 프로그램 종료 시 `System.exit()`를 호출하지 않았는가?
- 자바 코드 컨벤션을 지켰는가?
    - 기본적으로 [Java Style Guide](https://github.com/woowacourse/woowacourse-docs/blob/main/styleguide/java)를 원칙으로 한다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현했는가?
- 3항 연산자를 사용하지 않았는가?
- 함수(또는 메서드)가 한가지 일만 하도록 최대한 작게 만들었는가?
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인 가능한가?
- `camp.nextstep.edu.missionutils` 에서 제공하는 `Randoms` 및 `Console` API를 사용하여 구현하였는가?
    - Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의`pickNumberInRange()`를 활용한다.
    - 사용자가 입력하는 값은`camp.nextstep.edu.missionutils.Console`의`readLine()`을 활용한다.
